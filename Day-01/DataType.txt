# ☕ Java Primitive Data Types – Complete & Perfect Notes

Java me total **8 Primitive Data Types** hote hain:

| Type    | Size            | Range              |
| ------- | --------------- | ------------------ |
| byte    | 1 byte          | -128 to 127        |
| short   | 2 bytes         | -32,768 to 32,767  |
| int     | 4 bytes         | -2^31 to 2^31-1    |
| long    | 8 bytes         | -2^63 to 2^63-1    |
| float   | 4 bytes         | 7 digit precision  |
| double  | 8 bytes         | 15 digit precision |
| char    | 2 bytes         | 0 to 65,535        |
| boolean | 1 bit (logical) | true / false       |

# 🔹 5️⃣ Type Conversion

---

# ✅ Widening (Implicit / Automatic)

Small → Big
No data loss
Automatic conversion

Example:

```java
int a = 10;
long b = a;
float c = a;
double d = a;
System.out.println(a);
System.out.println(b);
System.out.println(c);
System.out.println(d);


```

✔ Safe conversion

---

# ❌ Auto conversion 

Big → Small
Data loss possible
User must cast

Example:

```java
float f = 1.7f;
int g = (int) f;
System.out.println(g);
   // 1
```

# 🔹 Overflow Example

```java
long a = Long.MAX_VALUE;
System.out.println(a);

int b = (int) a;
System.out.println(b);  // -1 (overflow)
```

Why?

Long = 64 bits
Int = 32 bits
Extra bits cut ho jate hain.
